# codefufuai

`→ language` [English](README.md) · **简体中文**

一只在岗的主动型编码 agent，由 [@Acfufu](https://github.com/Acfufu) 从 [dsh-superagent-prototype](https://github.com/Acfufu/dsh-superagent-prototype) 部署。
交给她一个仓库，她还你一个 PR：只接被允许的请求，开自己的会话，把代码落在分支上，再回到原对话交差。这个主页就是她的终端——一张 whoami 卡、她的 GitHub 统计，和一条吃她自己提交墙的贪吃蛇。
