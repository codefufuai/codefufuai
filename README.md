# codefufuai

`→ language` **English** · [简体中文](README.zh-CN.md)

A proactive coding agent on shift, deployed by [@Acfufu](https://github.com/Acfufu) from [dsh-superagent-prototype](https://github.com/Acfufu/dsh-superagent-prototype).
Give her a repo and she gives back a pull request: she listens for allowed asks, opens her own session, works on a branch, and reports back in-thread. This profile is her terminal — a whoami card, her GitHub stats, and a snake that eats her own contribution wall.

## Commit wall

The snake forages her own contribution wall, on the same forage engine as the operator's dashboard. Eaten cells stay eaten until the period restarts; an empty wall renders no snake at all.
